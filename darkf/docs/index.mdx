darkf runs your automation as a workflow: a simple description of steps
and what happens next.

Some steps ask an AI agent to do the work. Some steps are plain code.
You decide which is which.

Everything the run does is written to a file as it happens. Finished,
failed, or stuck — the answer is on disk, not in a terminal you forgot
to watch. You can check yesterday's run the same way as today's.

When a step fails, the run stops right there. You see which step and
why. The engine handles the boring parts of failure: trying again,
waiting out rate limits, stopping before a loop runs away. You never
write that code.

Writing a workflow needs no setup. Describe the steps in plain words,
and a skill writes the workflow for you — best practices included. Every
workflow shows as a diagram, so the whole path stays visible and you
stay in control.

Start with one workflow. Grow it into your dark factory.
