darkf runs a workflow — a plain TypeScript object describing states and
transitions — as a sequence of **agent** nodes (an LLM call) and **script**
nodes (a plain function), dispatched through one shared contract. It journals
every step to disk, so "did it finish, and how" is always answerable from a
file, not a live process.
